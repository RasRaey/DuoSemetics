# DuoSemetics — working notes

A Tigrinya (ትግርኛ) learning app in the shape of a daily-streak language game.
React + TypeScript + Vite, no runtime dependencies beyond React.

## Target device

**The owner uses an iPhone 15 Pro Max — design and test for it first.**

- Viewport 430×932pt at @3x (1290×2796 device pixels).
- Dynamic Island at the top, home indicator at the bottom: never hard-code
  offsets, always use `env(safe-area-inset-*)` (exposed as `--sat/--sab/--sal/--sar`
  in `index.css`).
- A screen that renders its own top bar gets `--sat` from `.topbar`. A screen
  without one — the Profile tab — must add the inset itself, or content ends up
  under the Dynamic Island.
- Launch images and icons are regenerated by `npm run icons`; the 1290×2796
  splash pair is the iPhone 15 Pro Max one.
- Verify visually with `node scripts/smoke.mjs`, which drives Chromium at exactly
  that viewport and writes to `shots/`.

It is installed via Safari → Share → Add to Home Screen, so it must keep working
as a standalone PWA: no reliance on browser chrome, and offline-safe.

## Shape of the code

```
src/data/       content only — lexicon, sentences, Fidel tables, curriculum
src/engine/     logic only, no React — generator, grading, SRS, store, RNG
src/audio/      Web Audio sound effects, speech synthesis
src/components/ screens and exercises
```

Keep that split. Adding a unit should mean editing `data/curriculum.ts` and
nothing else — the generator decides how to drill whatever a node declares.

`data/curriculum.ts` references ids in `lexicon.ts`, `sentences.ts` and
`fidel.ts`. Nothing validates those at build time beyond TypeScript's string
type, so when adding content, check the ids resolve.

## Conventions

- **No new runtime dependencies** without a good reason. Sounds are synthesised,
  icons are inline SVG, there is no CSS framework and no state library.
- Styling is CSS custom properties in `index.css` plus inline styles. Colours are
  always tokens (`var(--green)`), never literals, so dark mode keeps working.
- Every colour token has a matching `-ink` (the pressed/bottom-lip shade) and
  most have a `-soft`. Buttons and nodes rely on that pairing.
- Ge'ez text always gets `className="geez"` — it needs its own face and leading.
- Emoji are for content (a word's picture, a gem, a heart). Interface chrome uses
  the SVG set in `components/icons`.
- `localStorage` access is wrapped in try/catch: private mode and cleared storage
  must degrade to a working session, never a crash.

## Repository

The default branch is `claude/tigrigna-learning-app-tiw5q3` — GitHub made the
first pushed branch the default, and there is no `main`. The repository is
private; the Pages deploy workflow is manual because publishing would put the
built app on a public URL regardless.

## Progress is origin-scoped

`localStorage` belongs to one origin, so the same app served from a LAN address
and from a hosted URL are two separate save files. `exportProgress` /
`importProgress` in `engine/store.ts` and the **Back up or move** sheet in
`Profile.tsx` exist for that move. Keep the backup envelope
(`{ app: 'duosemetics', version, exportedAt, progress }`) stable, and route
restores through `importProgress` so an older backup gets migrated rather than
written in raw.

Offline needs a service worker, which needs a secure context. Over plain HTTP on
a LAN address there is no offline — only on HTTPS, or localhost.

## Testing

`npm run build && node scripts/smoke.mjs` plays a real lesson end to end at phone
size, checks every tab renders, checks progress survives a reload, and fails on
any same-origin runtime error. Run it after any change to the lesson flow.

`scripts/stress.mjs` covers what a clean playthrough never reaches: wrong
answers, hearts running out, Fidel drills, chests, unit reviews and practice.
Run it after touching hearts, the queue or the reward flow.

Both tests drive the app through an opt-in hook: `?e2e=1` publishes the current
exercise's `solve()` and `fail()` on `window.__e2e`. Keep that hook query-gated.

**Seed localStorage with `context.addInitScript`, never `page.evaluate` on a
loaded page.** The store saves on its own schedule and will silently overwrite a
write that lands after boot — this has produced two false test failures already.

## The hearts loop

Practice must stay free and must keep handing a heart back on completion
(`costHearts={false}` on the lesson, the `earnsHeart` branch in `App.finish`).
That is the only way out of zero hearts without paying gems or waiting, and the
out-of-hearts sheet points at it. Breaking either half strands the learner.

## Known gaps

- **No recorded audio.** No platform ships a Tigrinya speech voice, so the app
  falls back to an Amharic voice and then to reading the transliteration. Native
  speaker recordings are the single biggest improvement available.
- The league's rivals are locally generated, and the UI says so. Do not present
  them as real users.
- Content has been written carefully but has not been reviewed by a native
  speaker. Treat correction reports as high priority.
